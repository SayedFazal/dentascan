================================================================================
                        QUICK START (5 MINUTES)
================================================================================

1. CONFIGURE ENVIRONMENT:

   $ ipconfig  # Find your LAN IP (e.g., 192.168.1.100)

   Edit .env:
   VITE_API_URL=http://YOUR_LAN_IP:3000
   DATABASE_URL=postgresql://...your-neon-url...
   DEBUG=true

2. START SERVER:

   $ npm run dev

   Expected: Shows LAN IP in startup message

3. TEST WEB:

   Open: http://localhost:3000
   Register and login

4. BUILD ANDROID:

   $ npm run build
   $ npx cap sync android

   Build APK in Android Studio: Run → Run 'app'

5. TEST ANDROID:

   Register and login on device/emulator

   Check server logs show: [REGISTER SUCCESS] ... Platform: Android

================================================================================
                         TROUBLESHOOTING FLOW
================================================================================

Android app shows "Invalid response from authentication server":
  1. Check .env has correct VITE_API_URL with YOUR LAN IP
  2. Run: npm run build && npx cap sync android
  3. Rebuild APK in Android Studio
  ✓ If still fails → check Windows Firewall allows port 3000

Cannot reach backend from Android:
  1. Verify Android device on same WiFi network
  2. Run: adb shell ping YOUR_LAN_IP
  3. Check Windows Firewall: netsh advfirewall firewall show rule name="DentaScan Backend"
  ✓ If still fails → add firewall rule for port 3000

"Database connection error" on both platforms:
  1. Check .env DATABASE_URL is correct
  2. Test connection: psql "your-connection-string"
  3. Restart server: npm run dev
  ✓ If still fails → verify Neon connection string
